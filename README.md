# 🛒 Shopping Mission Interpreter

An NLP-powered application that reads a free-text grocery shopping request,
infers the shopper's intent and constraints, and recommends matching products
from a real retail catalog.

**NLP Group Project — Option 1: Application Development**

---

## What it does

A shopper types something like:

> *"I'm diabetic, need a filling breakfast that won't spike my sugar"*

The system:
1. **Parses the intent** — meal occasion, mission type, dietary constraints,
   preferences, budget, excluded items, and risk flags (including implicit
   safety constraints like "diabetic" → low_sugar)
2. **Recommends products** — semantically matched from 1,500+ real Instacart
   products, ranked by a match score (1–10) with one-line reasons

Two systems are compared side by side:
- **Keyword Baseline** — transparent rule-based system (no API)
- **LLM (gpt-4o-mini)** — schema-constrained prompt with few-shot examples

---

## Key findings

| Field | Keyword | LLM | Delta |
|---|---|---|---|
| meal_occasion | 0.940 | 0.960 | +0.020 |
| mission_type | 0.460 | 0.620 | +0.160 |
| dietary_constraints (F1) | 0.857 | 0.957 | +0.100 |
| risk_flags (F1) | 0.450 | 0.711 | +0.261 |
| excluded_items (F1) | 0.750 | 1.000 | +0.250 |

The LLM wins most on **risk_flags** (+0.261) and **excluded_items** (+0.250)
— the fields requiring linguistic inference. The keyword baseline ties on
**budget_sensitivity** (1.000 both) — explicit words like "cheap"/"premium"
don't need NLP.

The headline failure: *"Birthday cake but my daughter is celiac"* — the
keyword baseline returns empty `dietary_constraints`; the LLM correctly
infers `gluten_free` without the word "gluten" appearing.

## Quickstart

**1. Install dependencies**
```bash
pip install -r requirements.txt
```

**2. Add your OpenAI API key**
```bash
# create .env in the project root
echo "OPENAI_API_KEY=sk-..." > .env
```

**3. Build the product index (once)**
```bash
python src/build_product_index.py
```

**4. Run the app**
```bash
streamlit run src/app.py
```
Opens at http://localhost:8501

**5. Run the evaluation**
```bash
python src/evaluate.py          # keyword + LLM (~€0.012)
python src/generate_report.py   # produces results/report.html
```

Full step-by-step instructions including cost estimates and Q&A notes
are in **[SETUP.md](SETUP.md)**.

## Schema

The interpreter outputs a structured JSON object:

```json
{
  "meal_occasion":          "breakfast",
  "mission_type":           "health_goal",
  "dietary_constraints":    ["gluten_free"],
  "preference_constraints": ["low_sugar", "filling"],
  "budget_sensitivity":     "not_mentioned",
  "excluded_items":         [],
  "product_categories":     ["breakfast", "dairy_eggs"],
  "risk_flags":             ["allergy_or_safety"],
  "mission_summary":        "celiac-safe birthday cake for the daughter",
  "confidence":             0.9,
  "explanation":            "'celiac' → gluten_free; birthday → party_hosting"
}
```

Fields with a controlled vocabulary are scored with **accuracy** (single)
or **micro F1** (list). `mission_summary`, `confidence`, and `explanation`
are model outputs evaluated qualitatively.

---

## Evaluation

50 hand-labelled examples across three tiers:
- **Easy (16)** — explicit, literal requests
- **Medium (18)** — light inference of mission/preference
- **Hard (16)** — negation, conflicting goals, implicit safety constraints

Scored fields: `meal_occasion`, `mission_type`, `budget_sensitivity`
(accuracy), plus `dietary_constraints`, `preference_constraints`,
`product_categories`, `risk_flags`, `excluded_items` (micro F1).

## Two-stage pipeline

```
Free-text request
    │
    ▼
Stage 1 — Intent Parser (gpt-4o-mini)
    │  structured schema + mission_summary
    ▼
Stage 2 — Product Recommender (gpt-4o-mini)
    │  candidates pre-filtered by aisle + dietary safety rules
    ▼
Ranked product recommendations with match scores (1–10)
```

Cost per end-to-end request: ~€0.0007

## Data sources

- **Test set** — 50 examples hand-labelled by the project team

  (50,000 products, mapped to 13 Carrefour-derived coarse aisles)
- **Category taxonomy** — adapted from a prior Carrefour capstone project
